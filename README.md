# Zero Mobile Releases

Zero Mobile 0.2.138-alpha (build 141) has been withdrawn after Google Play Protect rejected the APK through both Zero's updater and Samsung My Files. The signed channel remains available for Developer Host discovery, but it currently offers no installable update and the public APK paths are intentionally absent.

The withdrawn APK bytes remain preserved in repository history for security analysis. This repository contains no application source, account credentials, provider tokens, or developer configuration.
