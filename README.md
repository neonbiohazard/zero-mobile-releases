# Zero Mobile Releases

Zero Mobile 0.2.137-alpha (build 140) has been withdrawn after a physical-device Google Play Protect safety block. The signed channel remains available for Developer Host discovery, but it currently offers no installable update and the public latest APK paths are intentionally absent.

The withdrawn APK bytes remain preserved in repository history for security analysis. This repository contains no application source, account credentials, provider tokens, or developer configuration.
